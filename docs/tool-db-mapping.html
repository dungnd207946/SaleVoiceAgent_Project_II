Ghi chú đọc bảng

  • Agent không đọc tenant_data.zones và tenant_data.media ở bất kỳ tool nào — zones chưa có tool nào dùng; media đi qua service :8015.
  • Mọi query tenant_data.* đều dính 2 filter ẩn: RLS theo tenant (GUC) và status='published' — row draft/archived hoặc khác tenant_id là vô hình với agent (đây chính là 2 nghi phạm của bug discover_projects → total: 0).
  • dispatcher.py bắt exception của tool → trả {"error": "tool X crashed: …"} cho LLM; kết quả JSON "sạch" đồng nghĩa query đã chạy thành công.
  • Redis (3 key/phiên meta / customer / state) là storage phiên, không phải DB nghiệp vụ — chỉ liệt kê khi tool ghi vào nó như nguồn sự thật (booking, escalate, update_customer).
